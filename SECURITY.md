# Security Policy

This project is a static web page with no server, no user accounts and no stored data.

If you find a security problem, for example a way for the page to run untrusted code, please report it privately through GitHub's [private vulnerability reporting](https://github.com/nader-eloshaiker/black-hole-light-paths/security/advisories/new) rather than opening a public issue.

Only the latest version on the `main` branch is supported.
